- T2 是冻结 student 的训练轨迹修正，不表示训练后的模型对照。局部核验只对应解锁这一写状态步骤；开灯是撤去指导后的后续执行。页面不声称执行了独立状态查询或返回信息 gate。
- A6 默认 Teacher 结构化 / Teacher 自由文本。两者同起始上下文、状态、首轮 actor seed；自由文本实际输出提前完成回执，执行随后漏掉重新创建。保留 Student 的真实成功，以及 GPT、无指导的实际建单和描述内容问题；它们不被包装为登录失败或指导来源优势。
- A1–A5 退出正式展示。catalog 退役 sales-order-header、sales-order-pricing、enter-before-rename、create-in-target-directory、lock-doors、convert-then-refuel。旧链接由共享加载器转到 A6，并清除旧分支/记录参数。原始文件和历史配置留档。
